# Accueil

Bienvenue dans **Synapse** : un vault [Obsidian](https://obsidian.md) (un dossier de notes Markdown reliées entre elles) affiché comme un graphe, publié sur GitHub Pages.

Ce vault d'exemple est aussi le mode d'emploi. Chaque point du graphe est une note, chaque trait est un lien écrit dans une note avec `[[double crochets]]`.

## Par où commencer

- [[Guide]] : comment construire un vault, créer des notes, les relier, les ranger dans des dossiers.
- [[Domaines]] : des structures toutes prêtes, que tu fasses des études, une entreprise, de la recherche, du code ou un projet perso.
- [[Le graphe de Synapse]] : comment se servir de cette page (cliquer, filtrer, chercher avec `Ctrl K`).

## La règle d'or

> [!tip] Une note, une idée, au moins un lien
> Une note ne sert que si on la retrouve. Chaque note est reliée à la note d'index de son dossier, et chaque index est relié à cette page d'accueil. Voir [[Dossiers et notes d'index]].
