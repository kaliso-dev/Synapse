# Études

| Dossier | Contient | Type de note |
| --- | --- | --- |
| `Matières/` | une note d'index par matière, puis une note par chapitre ou notion | cours |
| `Examens/` | une note par examen : date, programme, liens vers les notions | examen |
| `Fiches/` | les fiches de révision, chacune liée aux notions qu'elle résume | fiche |
| `Sources/` | livres, articles, vidéos ([[Utiliser des modèles\|modèle Source]]) | source |
| `Personnes/` | profs, camarades de groupe | personne |

**Les liens qui comptent** : chaque notion est liée à sa matière et aux notions dont elle dépend ; chaque examen liste les notions à réviser. Le graphe local (touche `L`) d'un examen montre alors tout ce qu'il faut revoir.

Voir aussi [[Recherche]] pour un mémoire. Retour aux [[Domaines]].
