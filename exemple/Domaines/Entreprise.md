# Entreprise

| Dossier | Contient | Type de note |
| --- | --- | --- |
| `Clients/` | une note par client : contacts, historique, projets | client |
| `Projets/` | une note par projet : objectif, étapes, statut, responsable | projet |
| `Réunions/` | un compte rendu par réunion, nommé avec la date | réunion |
| `Décisions/` | une note par décision importante : pourquoi, quand, par qui | décision |
| `Procédures/` | comment on fait les choses (onboarding, facturation…) | procédure |
| `Personnes/` | l'équipe, les partenaires | personne |

**Les liens qui comptent** : une réunion cite le client, le projet et les personnes présentes, et chaque décision cite la réunion où elle a été prise. On retrouve ainsi l'historique complet d'un client depuis sa note (rubrique « Mentionnée dans »).

Les statuts (`en cours`, `fini`, `en pause`) vont dans les [[Propriétés et tags|propriétés]], pas dans des dossiers. Retour aux [[Domaines]].
