# Création

Pour un musicien, un écrivain, un illustrateur, un vidéaste…

| Dossier | Contient |
| --- | --- |
| `Œuvres/` | une note par œuvre en cours ou finie : intention, étapes, versions |
| `Inspirations/` | images, citations, références, avec ce qu'elles t'inspirent |
| `Techniques/` | ce que tu apprends : une note par technique ou outil |
| `Carnet/` | une note par jour ou par séance de travail |
| `Univers/` | pour une fiction : personnages, lieux, chronologie |

Les images vont dans `Fichiers/` et s'affichent dans les notes avec `![[image.png]]` (voir [[Pièces jointes]]). Retour aux [[Domaines]].
