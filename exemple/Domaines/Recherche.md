# Recherche

| Dossier | Contient |
| --- | --- |
| `Sources/` | une note par article ou livre : référence, résumé, citations |
| `Idées/` | une note par idée ou concept, dans tes mots (« notes permanentes ») |
| `Expériences/` | protocole, résultats, conclusions, datés |
| `Rédaction/` | les plans et chapitres, qui assemblent les idées |
| `Personnes/` | auteurs, collègues, encadrants |

**La méthode** : en lisant, on crée une note Source ; chaque idée qu'on en tire devient une note dans `Idées/`, liée à sa source et aux autres idées. Au moment d'écrire, le graphe montre les grappes d'idées déjà reliées : ce sont les chapitres.
