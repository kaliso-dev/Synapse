# Domaines

Le même vault marche pour n'importe quel sujet : seuls les dossiers et les types de notes changent. Voici des points de départ, à adapter. Retour à l'[[Accueil]].

- [[Études]] : cours, matières, examens, fiches de révision.
- [[Entreprise]] : clients, projets, réunions, décisions, procédures.
- [[Projet logiciel]] : fonctionnalités, architecture, bugs, versions.
- [[Recherche]] : sources, idées, expériences, rédaction.
- [[Création]] : œuvres, inspirations, techniques, carnets.
- [[Vie perso]] : objectifs, santé, finances, voyages, lectures.

Dans tous les cas : un dossier par catégorie de choses, une note d'index par dossier, l'accueil qui relie les index. Voir [[Dossiers et notes d'index]].
