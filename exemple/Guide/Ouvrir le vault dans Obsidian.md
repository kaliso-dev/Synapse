# Ouvrir le vault dans Obsidian

Synapse sert à **lire** et à montrer le vault. Pour **écrire** confortablement sur ton ordinateur, utilise Obsidian (gratuit).

1. Installe [Obsidian](https://obsidian.md/download).
2. Récupère le dépôt sur ton ordinateur : avec [GitHub Desktop](https://desktop.github.com) (File → Clone repository), ou `git clone` si tu connais Git.
3. Dans Obsidian : « Ouvrir un dossier comme coffre » et choisis le dossier du vault (par exemple `vault/` dans le dépôt).
4. Pour renvoyer tes changements sur GitHub : GitHub Desktop (Commit puis Push), ou le module communautaire **Obsidian Git** qui le fait tout seul toutes les quelques minutes.

Chaque envoi sur GitHub reconstruit le site : la nouvelle version est en ligne une minute plus tard (voir [[Publier sur GitHub Pages]]).

> [!tip] Sans ordinateur
> Sur téléphone, l'app Obsidian marche aussi. Et rien n'empêche de demander à Claude d'écrire les notes pour toi : voir [[Travailler avec Claude]].
