# Le graphe de Synapse

Chaque point est une note ; sa couleur est celle de son dossier de premier niveau, sa taille dépend de son nombre de liens. Les traits sont les liens écrits dans les notes.

| Geste | Effet |
| --- | --- |
| Clic sur un point | ouvre la note dans le lecteur à droite |
| Survol | allume la note et ses voisines, des impulsions parcourent ses liens |
| Glisser un point | le déplace (le graphe suit) |
| Glisser le fond, molette, pincer | se déplacer et zoomer |
| `Ctrl K` ou `/` | chercher une note, un mot, un fichier |
| `F` | tout voir |
| `L` | graphe local : seulement les voisins de la note ouverte (1 à 3 niveaux) |
| `Échap` | fermer le lecteur |

## Les panneaux

- **Fichiers** : l'arbre des notes, rangé comme les dossiers du vault, et les pièces jointes.
- **Affichage** : le thème (auto, clair, sombre), les dossiers à montrer, les fichiers, tags et notes à créer, les forces du graphe, et les chiffres du vault.
- **Filtrer le graphe** (en haut à gauche) : estompe ce qui ne correspond pas. `#tag` filtre sur un tag.

Dans le lecteur, chaque note montre ses propriétés ([[Propriétés et tags]]), sa table des matières, les notes qui la mentionnent et ses liens sortants. Le bouton lien copie l'adresse de la note, à partager.
