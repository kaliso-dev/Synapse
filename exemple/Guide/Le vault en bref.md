# Le vault en bref

Un **vault** (un « coffre ») est simplement un dossier qui contient des fichiers texte au format Markdown (`.md`). Rien d'autre : pas de base de données, pas de format fermé. On peut le lire avec n'importe quel éditeur de texte, le versionner avec Git, le publier sur GitHub.

[Obsidian](https://obsidian.md) est l'application qui rend ce dossier agréable : elle affiche les notes, suit les liens, montre les notes qui pointent vers celle qu'on lit, et dessine le graphe. **Synapse** fait la même chose dans une page web, pour que tout le monde puisse le consulter sans rien installer.

## Ce qu'on y met

Tout ce qui mérite d'être retrouvé plus tard : des idées, des cours, des comptes rendus, des décisions, des personnes, des projets, des sources. Le domaine n'a aucune importance : la méthode est la même partout (voir [[Domaines]]).

## Les trois règles

1. Une note par idée ou par chose : voir [[Créer une note]].
2. Chaque note est reliée à d'autres : voir [[Relier les notes]].
3. Les dossiers rangent, les liens relient : voir [[Dossiers et notes d'index]].
